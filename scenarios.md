# Сценарии тестирования формы регистрации пользователя

## Сценарий 1
- **ID:** Регистрация_01
- **Название:** Успешная регистрация пользователя с корректными данными
- **Тип:** Позитивный
- **Предварительные условия:** Пользователь не зарегистрирован на сайте
- **Шаги:**
  1. Откройте форму регистрации на сайте.
  2. Введите имя пользователя в поле "Имя пользователя".
  3. Введите пароль в поле "Пароль".
  4. Введите тот же пароль в поле "Подтвердите пароль".
  5. Нажмите кнопку "Зарегистрировать".
- **Ожидаемый результат:** Появляется сообщение об успешной регистрации или пользователь переходит на страницу личного кабинета.
